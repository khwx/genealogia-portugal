Sobre o Projeto

O que é este projeto?

Este projeto visa extrair, transcrever e disponibilizar os registos de óbitos do concelho de Celorico da Beira (distrito da Guarda, Portugal) que estão disponíveis em formato digital nos arquivos nacionais.

Os registos abrangem um período desde 1654 até 1911, e incluem registos paroquiais e civis das 27 freguesias do concelho.

Fontes de Dados
  • Tombo.pt - Portal de registos paroquiais portugueses
  • Digitarq - Arquivo digital da DGLAB com imagens dos registos originais
  • FamilySearch - Índices já transcritos de registos paroquiais
  • Transkribus - Transcrição HTR (Handwritten Text Recognition) para manuscritos antigos
Tecnologias Utilizadas
  • Python 3.8+
  • BeautifulSoup / Requests (web scraping)
  • SQLite (base de dados)
  • Pandas (exportação Excel/CSV)
  • Flask (interface web)
  • FamilySearch API
  • Transkribus API
Aviso Legal

Todos os dados neste projeto são de domínio público. Os registos de óbitos têm mais de 100 anos, não existindo qualquer restrição de proteção de dados (RGPD).
